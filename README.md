# Vendas Camisolas

Aplicação Flutter para gerir encomendas e vendas de equipamentos de futebol.

## Instalação

1. Cria um projeto Flutter vazio ou abre esta pasta.
2. Se esta pasta ainda não tiver as pastas `android`, `ios`, etc., executa:
   `flutter create .`
3. Executa:
   `flutter pub get`
4. Para testar:
   `flutter run`
5. Para gerar APK:
   `flutter build apk --release`

O APK fica normalmente em:
`build/app/outputs/flutter-apk/app-release.apk`
